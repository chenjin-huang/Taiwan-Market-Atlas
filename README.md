# 台灣產業市場圖譜 · Taiwan Market Atlas

Interactive network atlas of Taiwan's economy (200 nodes, 15 clusters).

- 繁體中文：`index.html`
- English：`en/index.html`

Self-contained: D3 v7.8.5 is bundled in `assets/`, no external fonts or CDNs, so it loads in WeChat's in-app browser.

Node sizes and links are a structural model, not measured flows. GDP shares: services 55.1%, industry 43.5% (manufacturing 38.6%), agriculture 1.4%.
